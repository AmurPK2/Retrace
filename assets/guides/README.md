# RETRACE 0.4.0 guides

Six Norwegian offline guides, updated against the actual integrated packaged UI in an isolated public demonstration profile. Genuine historical prices and screenshots; no private sessions, generated charts or third-party video footage. Narration is reused where accurate and regenerated for changed navigation, risk and learning progress. Voice overrides are recorded per scene. Captions, audio and fullscreen are checked in the distributed app. Open **Lær og øv** for a step guide or the complete library.

PO3 source notes and limitations: [HTF sources](../../docs/HTF-SOURCES.md).
