# RETRACE 0.5.0 · RR: see and do

Learn and practise now opens a visual RR path by default. Eight steps use an isolated, frozen view of the session's genuine historical candles: candle anatomy, a fixed C1 range, C2 wick/close relationships, the same period on 4H/15m/1m, a three-candle FVG, an explicit local-close exercise, a draggable price plan and review after locking.

**Vis meg** shows the relevant levels, numbered candles and explanation. **Prøv selv** hides the answer key until submission. Pick prices/candles on the chart, use keyboard selection or optional precise price inputs, and drag ENTRY/SL/TP independently. Computed feedback names the actual prices and corrects the specific error. Nearby labels use connectors to their true price levels.

The path does not move the main replay cursor, trade, change drawings or rewrite the older learning history. It pauses replay when opened. C3 data is withheld from the lesson view until a plan or Wait and a review answer are locked. Reveal uses already available historical C3; it never advances the owner's replay. Gaps remain gaps. Attempts persist by session and instrument and are included in session backups. Imported checks are recalculated.

The earlier ten-step written course, its retained answers and six offline Norwegian videos remain under **Tekst, videoer og tidligere kurs**. The RR source buttons retain their original references; FVG has a separate ICT primary source. No private sessions, source messages, account data, raw datasets or copied member recordings are redistributed.

## Exact learning boundaries

This teaches sourced RR building blocks with original interactive exercises. It is not a verified complete clone of every Jake/RR entry model. The eight-bar local confirmation level and the stop outside the reference pair are explicitly declared exercise rules, not universal RR/CISD rules. All candles used as confirmation must be complete at the frozen decision cutoff. A pre-4H-close lower-frame event cannot become a post-close entry retroactively.

Factual quiz completion, guided attempts and demonstrated trading skill are different. No automatic general mastery is awarded; the path does not certify an edge, winning probability or strategy profitability. Geometric patterns and a later winning candle cannot prove an entry, executable fill or good decision. Planned R:R is price geometry before spread and costs. General free chart-coach reasoning retains the documented 0.4.0 limits; this update does not certify it.
