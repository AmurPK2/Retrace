# RETRACE 0.6.0

Lær og øv now opens RR fra originalkildene: eight modules with visual, source-linked tasks covering the documented RR/Jake framework and its variants. It also includes the newly available recording 14, with four equal partials and protected-swing explanations. Original teaching diagrams are labelled and never passed off as market data or copied member screenshots.

Each task has a question beside the chart, source timestamps, a model boundary, guided and unassisted modes, persisted attempts and specific correction. Range and C2 stop tasks use draggable markers; risk and partial tasks use checked numerical answers. Chart levels and zones can be selected directly. The course works offline; opening the original YouTube videos needs internet and any access required by their owner.

The invented eight-bar confirmation test is retired, and free replay plans no longer enforce a blanket full-C1/C2-wick stop. Existing sessions, drawings, chat, broker state and older learning history are preserved.

The published streams explicitly disclose that they teach only part of Jake's confluence. This release teaches the available explanations and openly marks missing definitions; it does not claim to supply undisclosed full-strategy rules or demonstrate a profitable edge. See RR-SOURCE-COURSE.md for review method and coverage.
